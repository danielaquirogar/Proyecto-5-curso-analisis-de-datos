# Proyecto-5-curso-analisis-de-datos
Proyecto 5: Algoritmia y Criptografía Simétrica Aplicada (Python)

Desarrollé un software de cifrado por sustitución simétrica (ROT13 optimizado para el idioma español) que procesa
caracteres especiales, mayúsculas y la letra "Ñ".

Implementé un módulo de pruebas unitarias y automáticas (Unit Testing) para garantizar el correcto funcionamiento
del algoritmo ante fallos perimetrales.
